📁 Guía: Subir un Proyecto Local a GitHub

Versión: 1.0

Autor: Yosh Pardo

Fecha: 02/05/2025

🔧 Requisitos Previos

  • Git instalado (git --version).
  • Cuenta en GitHub y repositorio remoto creado.
  • Archivos de tu proyecto listos para subir.

📌 Pasos para Subir un Proyecto

1. Crear un Repositorio en GitHub

  1. Inicia sesión en GitHub.
  2. Haz clic en "New repository".
  3. Asigna un nombre y deja el repositorio vacío.
  4. Copia la URL del repositorio (ej: https://github.com/tu-usuario/mi-proyecto.git).

2. Configurar Git Localmente

git config --global user.name "TuNombre"
git config --global user.email "tu-email@example.com"

3. Inicializar el Repositorio Local

cd ruta/de/tu/proyecto
git init
git add .
git commit -m "Primer commit"

4. Conectar con el Repositorio Remoto

git remote add origin https://github.com/tu-usuario/mi-proyecto.git
git remote -v

5. Subir los Archivos a GitHub

Caso 1: Repositorio Remoto Vacío

git push -u origin main

Caso 2: Repositorio Remoto con Archivos

git pull origin main --allow-unrelated-histories
git add .
git commit -m "Merge historial remoto"
git push origin main

Caso 3: Forzar Subida (Solo si trabajas solo)

git push --force origin main

⚠️ Errores Comunes y Soluciones

Error: fatal: refusing to merge unrelated histories

Solución: Usa --allow-unrelated-histories al hacer pull o merge.

Error: [rejected - non-fast-forward]

Solución: Actualiza tu rama local con git pull origin main.

💡 Consejos Adicionales

  • Usa ramas secundarias (dev, feature) para evitar conflictos.
  • Personaliza tu editor de Git (ej: VS Code):
    • git config --global core.editor "code --wait"

📄 Ejemplo Completo

git init
git add .
git commit -m "Primer commit"
git remote add origin https://github.com/tu-usuario/mi-proyecto.git
git pull origin main --allow-unrelated-histories
git add .
git commit -m "Merge historial"
git push origin main
